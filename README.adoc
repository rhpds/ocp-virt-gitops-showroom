= OpenShift Virtualization GitOps Showroom

Showroom lab guide for the OpenShift Virtualization GitOps workshop, built with https://antora.org[Antora].

Content covers four demos:

* Manual change detection and drift correction
* VM recovery from data loss
* Adding a new development VM via Git
* Multi-environment VM management with Kustomize

== Quick Start

. Clone this repository
. Preview locally:
+
[source,sh]
----
podman run --rm --name antora -v $PWD:/antora -p 8080:8080 -i -t ghcr.io/juliaaano/antora-viewer
----
+
On SELinux systems, append `:z` to the volume mount.

. Edit content in `content/modules/ROOT/pages/`

Source workshop guides: https://github.com/anibalcoral/OpenShift-Virtualization-GitOps/tree/main/demo-guides[`demo-guides/` in OpenShift-Virtualization-GitOps]
