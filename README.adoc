= OpenShift Virtualization GitOps Showroom

Lab guide for the **OpenShift Virtualization GitOps** workshop, built with https://antora.org[Antora] for the https://demo.redhat.com[Red Hat Demo Platform] Showroom.

This repository replaces the old Markdown guides from the workshop-app (`demo-guides/`) with AsciiDoc content rendered in Showroom.

== What this workshop covers

GitOps for Virtual Machines on OpenShift Virtualization using OpenShift GitOps (ArgoCD):

* *Demo 1* -- Manual change detection and drift correction
* *Demo 2* -- VM recovery from data loss
* *Demo 3* -- Adding a new development VM via Git
* *Demo 4* -- Multi-environment VM management with Kustomize

Supporting pages: workshop overview, installation details, GitOps promotion workflow, troubleshooting, and cleanup.

== Content layout

[source,text]
----
content/
└── modules/ROOT/
    ├── antora.yml          # Component descriptor + AsciiDoc attributes
    ├── nav.adoc            # Left navigation
    └── pages/
        ├── index.adoc
        ├── 01-overview.adoc
        ├── 02-details.adoc
        ├── 03-demo-01-manual-change.adoc
        ├── 04-demo-02-vm-recovery.adoc
        ├── 05-demo-03-add-development-vm.adoc
        ├── 06-demo-04-multi-env-management.adoc
        ├── 07-gitops-workflow.adoc
        ├── 08-troubleshooting.adoc
        └── 99-conclusion.adoc
----

Runtime variables such as `{guid}` are injected as AsciiDoc attributes (see `content/antora.yml`).

== Preview locally

[source,sh]
----
podman run --rm --name antora \
  -v "$PWD:/antora:z" \
  -p 8080:8080 \
  -i -t ghcr.io/juliaaano/antora-viewer
----

Open http://localhost:8080

Edit files under `content/modules/ROOT/pages/` -- the viewer rebuilds on change.
