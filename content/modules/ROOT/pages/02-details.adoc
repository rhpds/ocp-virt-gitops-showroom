== Lab environment

This lab is pre-provisioned. OpenShift Virtualization, OpenShift GitOps (Argo CD), namespaces, and Argo CD Applications are already installed. You do not need to run any installation scripts.

Log in as the lab admin from the Showroom terminal (required before `oc` commands):

[source,subs="attributes+",role="execute"]
----
oc login -u {openshift_cluster_admin_username} -p '{openshift_cluster_admin_password}' \
  --server={openshift_api_server_url} --insecure-skip-tls-verify=true
oc whoami
oc get applications -n openshift-gitops
----

== Clone the Apps Git repository

Demos 3 and 4 edit VM manifests in Git. Clone the Gitea Apps repo into your home directory (there is no `/opt/...` checkout in this lab).

[source,subs="attributes+",role="execute"]
----
cd ~
git clone https://{gitea_user}:{gitea_password}@gitea.{openshift_cluster_ingress_domain}/{gitea_user}/ocp-virt-gitops-apps.git
cd ~/ocp-virt-gitops-apps
git remote -v
git branch -a
----

Credentials (also available in lab userdata):

* *Gitea URL*: `{gitea_console_url}`
* *User*: `{gitea_user}`
* *Password*: `{gitea_password}`
* *Repo*: `{gitea_console_url}/{gitea_user}/ocp-virt-gitops-apps`

Working branches (no GUID suffix):

* `vms-dev` -- development
* `vms-hml` -- homologation
* `vms-prd` -- production

If the clone already exists, reuse it:

[source,role="execute"]
----
cd ~/ocp-virt-gitops-apps
git fetch --all
----

== Environment verification

Verify Argo CD Applications and VMs are present:

[source,role="execute"]
----
oc get applications -n openshift-gitops
oc get vms -n workshop-gitops-vms-dev
oc get vms -n workshop-gitops-vms-hml
oc get vms -n workshop-gitops-vms-prd
----

Expected Argo CD applications:

[source,text]
----
NAME                        SYNC STATUS   HEALTH STATUS
workshop-gitops-vms-dev     Synced        Healthy
workshop-gitops-vms-hml     Synced        Healthy
workshop-gitops-vms-prd     Synced        Healthy
----

Expected virtual machines:

[source,text]
----
NAMESPACE                   NAME            STATUS
workshop-gitops-vms-dev     dev-vm-web-01   Running
workshop-gitops-vms-dev     dev-vm-web-02   Running
workshop-gitops-vms-hml     hml-vm-web-01   Running
workshop-gitops-vms-hml     hml-vm-web-02   Running
workshop-gitops-vms-prd     prd-vm-web-01   Running
workshop-gitops-vms-prd     prd-vm-web-02   Running
----

If an Application shows `OutOfSync` or `Missing`, sync it:

[source,role="execute"]
----
for app in workshop-gitops-vms-dev workshop-gitops-vms-hml workshop-gitops-vms-prd; do
  oc patch applications "$app" -n openshift-gitops --type merge \
    -p '{"operation":{"initiatedBy":{"username":"admin"},"sync":{"revision":"HEAD"}}}'
done
----
