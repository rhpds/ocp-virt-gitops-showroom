= Workshop Details
:source-highlighter: rouge


== Prerequisites

* OpenShift cluster with OpenShift Virtualization installed
* `oc` CLI configured and logged in
* `ansible-playbook` installed
* Git repositories configured

== Installation

=== Automated installation

[source,role="execute"]
----
./install.sh
----

What the automated installation does:

. Validates prerequisites (`oc` CLI and cluster login)
. Installs OpenShift GitOps Operator
. Creates RBAC permissions
. Creates workshop namespaces for all environments (dev, hml, prd)
. Creates ArgoCD applications for all environments
. Displays ArgoCD credentials for access

=== Manual installation

For detailed workshop demonstrations, you can install components step by step using the pre-created YAML files:

. Install GitOps Operator:
+
[source,role="execute"]
----
oc apply -f manual-install-files/01-gitops-operator-subscription.yaml
----

. Create RBAC permissions:
+
[source,role="execute"]
----
oc apply -f manual-install-files/02-cluster-role-binding.yaml
----

. Create namespaces:
+
[source,role="execute"]
----
oc apply -f manual-install-files/03-namespaces.yaml
----

. Create ArgoCD applications:
+
[source,role="execute"]
----
oc apply -f manual-install-files/04-argocd-app-dev.yaml
oc apply -f manual-install-files/05-argocd-app-hml.yaml
oc apply -f manual-install-files/06-argocd-app-prd.yaml
----

=== Installation verification

After installation, verify everything is working:

[source,role="execute"]
----
oc get applications -n openshift-gitops
oc get vms -n workshop-gitops-vms-dev
oc get vms -n workshop-gitops-vms-hml
oc get vms -n workshop-gitops-vms-prd
oc get vmi -A
/opt/OpenShift-Virtualization-GitOps/run-demos.sh s
----

== Workshop demonstrations

The workshop includes four demonstrations. All are automated through Ansible playbooks and also documented with manual step-by-step instructions.

=== Interactive demo runner

[source,role="execute"]
----
/opt/OpenShift-Virtualization-GitOps/run-demos.sh
----

Available options:

* `1-4`: Execute individual demos with full automation
* `a`: Run all demos sequentially with validation between each
* `s`: Check comprehensive workshop status across all environments
* `c`: Cleanup Demo 4 resources for repeatability
* `q`: Quit the demo runner

=== Demo 1: Manual change detection and drift correction

*Purpose*: Demonstrate how ArgoCD detects and corrects configuration drift.

Run with the demo runner:

[source,role="execute"]
----
/opt/OpenShift-Virtualization-GitOps/run-demos.sh 1
----

Or with Ansible directly:

[source,role="execute"]
----
ansible-playbook -i /opt/OpenShift-Virtualization-GitOps/inventory/localhost \
  /opt/OpenShift-Virtualization-GitOps/playbooks/demo1-manual-change.yaml
----

Detailed manual steps: xref:03-demo-01-manual-change.adoc[Demo 1].
