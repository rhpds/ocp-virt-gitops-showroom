== Lab environment

This lab is pre-provisioned. OpenShift Virtualization, OpenShift GitOps (Argo CD), namespaces, and Argo CD Applications are already installed. You do not need to run any installation scripts.

Log in as the lab admin from the Showroom terminal (required before `oc` commands):

[source,subs="attributes+",role="execute"]
----
oc login -u {openshift_cluster_admin_username} -p '{openshift_cluster_admin_password}' --server={openshift_api_server_url} --insecure-skip-tls-verify=true
----

Confirm the current OpenShift user:

[source,role="execute"]
----
oc whoami
----

List Argo CD Applications for the demo:

[source,role="execute"]
----
oc get applications -n openshift-gitops
----

[IMPORTANT]
====
At lab start the Argo CD Applications often show `OutOfSync` or `Missing`.
Automatic sync is disabled in this demo, so you may need to sync all three Applications now before starting the lab.
====

Sync the development Argo CD Application:

[source,role="execute"]
----
oc patch applications workshop-gitops-vms-dev -n openshift-gitops --type merge -p '{"operation":{"initiatedBy":{"username":"admin"},"sync":{"revision":"HEAD"}}}'
----

Sync the homologation Argo CD Application:

[source,role="execute"]
----
oc patch applications workshop-gitops-vms-hml -n openshift-gitops --type merge -p '{"operation":{"initiatedBy":{"username":"admin"},"sync":{"revision":"HEAD"}}}'
----

Sync the production Argo CD Application:

[source,role="execute"]
----
oc patch applications workshop-gitops-vms-prd -n openshift-gitops --type merge -p '{"operation":{"initiatedBy":{"username":"admin"},"sync":{"revision":"HEAD"}}}'
----

Confirm all Applications report `Synced` and `Healthy`:

[source,role="execute"]
----
oc get applications -n openshift-gitops -o custom-columns="NAME:.metadata.name,SYNC:.status.sync.status,HEALTH:.status.health.status"
----

== Clone the Apps Git repository

Demos 3 and 4 edit VM manifests in Git. Clone the Gitea Apps repo into your home directory (there is no `/opt/...` checkout in this lab).

Go to your home directory:

[source,role="execute"]
----
cd ~
----

Clone the Apps repository from Gitea:

[source,subs="attributes+",role="execute"]
----
git clone https://{gitea_user}:{gitea_password}@gitea.{openshift_cluster_ingress_domain}/{gitea_user}/ocp-virt-gitops-apps.git
----

Enter the Apps repository:

[source,role="execute"]
----
cd ~/ocp-virt-gitops-apps
----

Show configured Git remotes:

[source,role="execute"]
----
git remote -v
----

List local and remote branches:

[source,role="execute"]
----
git branch -a
----

[IMPORTANT]
====
The Showroom terminal has no Git author identity configured.
Set it once before any `git commit` in Demo 3 or Demo 4.
Without this, commits fail and `git push` reports `src refspec vms-dev does not match any`.
====

Configure Git user name:

[source,role="execute"]
----
git config --global user.name "Lab User"
----

Configure Git user email:

[source,role="execute"]
----
git config --global user.email "lab-user@example.com"
----

Switch to the development branch (do not work on `main`):

[source,role="execute"]
----
git checkout vms-dev
----

Credentials (also available in lab userdata):

* *Gitea URL*: `{gitea_console_url}`
* *User*: `{gitea_user}`
* *Password*: `{gitea_password}`
* *Repo*: `{gitea_console_url}/{gitea_user}/ocp-virt-gitops-apps`

Working branches (no GUID suffix):

* `vms-dev` -- development
* `vms-hml` -- homologation
* `vms-prd` -- production

If the clone already exists, reuse it:

Enter the existing Apps repository:

[source,role="execute"]
----
cd ~/ocp-virt-gitops-apps
----

Fetch latest changes from all remotes:

[source,role="execute"]
----
git fetch --all
----

== Environment verification

List Argo CD Applications:

[source,role="execute"]
----
oc get applications -n openshift-gitops
----

List VMs in the development namespace:

[source,role="execute"]
----
oc get vms -n workshop-gitops-vms-dev
----

List VMs in the homologation namespace:

[source,role="execute"]
----
oc get vms -n workshop-gitops-vms-hml
----

List VMs in the production namespace:

[source,role="execute"]
----
oc get vms -n workshop-gitops-vms-prd
----

Expected Argo CD applications:

[source,text]
----
NAME                        SYNC STATUS   HEALTH STATUS
workshop-gitops-vms-dev     Synced        Healthy
workshop-gitops-vms-hml     Synced        Healthy
workshop-gitops-vms-prd     Synced        Healthy
----

Expected virtual machines:

[source,text]
----
NAMESPACE                   NAME            STATUS
workshop-gitops-vms-dev     dev-vm-web-01   Running
workshop-gitops-vms-dev     dev-vm-web-02   Running
workshop-gitops-vms-hml     hml-vm-web-01   Running
workshop-gitops-vms-hml     hml-vm-web-02   Running
workshop-gitops-vms-prd     prd-vm-web-01   Running
workshop-gitops-vms-prd     prd-vm-web-02   Running
----

If any Application is still `OutOfSync` or `Missing`, re-run the three sync commands from <<Lab environment>> and wait until VMs reach `Running`.
