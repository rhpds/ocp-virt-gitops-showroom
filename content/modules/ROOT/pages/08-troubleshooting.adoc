= Monitoring and Troubleshooting
:source-highlighter: rouge


== Status checking

Check Argo CD Applications and VMs across environments:

[source,role="execute"]
----
# List Argo CD Applications
oc get applications -n openshift-gitops
----

[source,role="execute"]
----
# List VMs in the development namespace
oc get vms -n workshop-gitops-vms-dev
----

[source,role="execute"]
----
# List VMs in the homologation namespace
oc get vms -n workshop-gitops-vms-hml
----

[source,role="execute"]
----
# List VMs in the production namespace
oc get vms -n workshop-gitops-vms-prd
----

== Common issues and solutions

=== SSH access issues

[source,role="execute"]
----
# Check the SSH secret in development
oc get secret workshop-gitops-vms-dev -n workshop-gitops-vms-dev
----

[source,role="execute"]
----
# Check the SSH secret in homologation
oc get secret workshop-gitops-vms-hml -n workshop-gitops-vms-hml
----

[source,role="execute"]
----
# Check the SSH secret in production
oc get secret workshop-gitops-vms-prd -n workshop-gitops-vms-prd
----

Check VM access credentials:

[source,role="execute"]
----
# Inspect accessCredentials on a VM
oc get vm <vm-name> -n <namespace> -o yaml | grep -A 10 accessCredentials
----

Clean known hosts before reconnecting:

[source,role="execute"]
----
# Remove a stale SSH known_hosts entry
ssh-keygen -R <vm-ip-or-hostname>
----

=== Argo CD application issues

[source,role="execute"]
----
# List Argo CD Applications
oc get applications -n openshift-gitops
----

[source,role="execute"]
----
# Describe the development Application
oc describe applications workshop-gitops-vms-dev -n openshift-gitops
----

Force application sync if needed:

[source,role="execute"]
----
# Force sync of the development Application
oc patch applications workshop-gitops-vms-dev -n openshift-gitops --type merge --patch '{"operation":{"initiatedBy":{"username":"admin"},"sync":{"revision":"HEAD"}}}'
----

=== Repository access issues

[source,role="execute"]
----
# List repository secrets in openshift-gitops
oc get secret -n openshift-gitops | grep -i repo
----

[source,role="execute"]
----
# Inspect the Application source configuration
oc get applications workshop-gitops-vms-dev -n openshift-gitops -o yaml | grep -A20 source
----

== Regular monitoring commands

=== Check application status

[source,role="execute"]
----
# List Argo CD Applications
oc get applications -n openshift-gitops
----

=== Check sync status

[source,role="execute"]
----
# Show full YAML for the development Application
oc get applications workshop-gitops-vms-dev -n openshift-gitops -o yaml
----

=== Access Argo CD UI

[source,role="execute"]
----
# Get the Argo CD server route
oc get route openshift-gitops-server -n openshift-gitops
----

[source,role="execute"]
----
# Print the Argo CD admin password
oc get secret openshift-gitops-cluster -n openshift-gitops -o jsonpath='{.data.admin\.password}' | base64 -d; echo
----
