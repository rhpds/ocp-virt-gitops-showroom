= Cleanup and Best Practices
:source-highlighter: rouge

== Cleanup Demo 3 or Demo 4 resources

To reset resources created during Demo 3 or Demo 4 so you can repeat those labs, follow the cleanup steps at the end of each demo module. Do not uninstall operators, Applications, or namespaces -- those belong to the lab provisioning lifecycle.

== VM templates

All VMs use the Fedora template with cloud-init for initial configuration:

* Default user: `cloud-user`
* Default password: `redhat123`
* SSH access configured
* Environment-specific applications installed

== Argo CD configuration details

Each Argo CD application is configured with:

* *Automatic Sync*: Disabled (manual sync operations)

== Best practices demonstrated

. *Infrastructure as Code*: All VM definitions stored in Git
. *Environment Separation*: Different branches for different environments
. *Manual Deployment*: Changes deployed via Argo CD manual sync operations
. *Drift Detection*: Manual changes detected and corrected
. *Disaster Recovery*: Complete environment recovery from Git
. *Security*: Proper RBAC and namespace isolation
