== OpenShift CLI access

Log in as the demo admin from the Showroom terminal before running commands:

[source,subs="attributes+",role="execute"]
----
oc login -u {openshift_cluster_admin_username} -p '{openshift_cluster_admin_password}' --server={openshift_api_server_url} --insecure-skip-tls-verify=true
----

Confirm the current OpenShift user:

[source,role="execute"]
----
oc whoami
----

List Argo CD Applications for the demo:

[source,role="execute"]
----
oc get applications -n openshift-gitops
----

Expected: `oc whoami` returns `{openshift_cluster_admin_username}`, and the Applications list shows `workshop-gitops-vms-dev`, `workshop-gitops-vms-hml`, and `workshop-gitops-vms-prd`.

== Git author identity (required)

The Showroom terminal has **no** Git `user.name` or `user.email`. Without these, every `git commit` fails and Demo 3 / Demo 4 cannot push. Run both commands once at the start of the demo:

Configure Git user name:

[source,role="execute"]
----
git config --global user.name "lab-user"
----

Configure Git user email:

[source,role="execute"]
----
git config --global user.email "lab-user@example.com"
----
